# greeter

A deliberately tiny library, used to exercise Maestro's pipeline end to end.

It exists so that a task has somewhere real to land: a couple of source files, a test suite that
runs in a second, and a CI workflow that actually reports back to a pull request. Nothing here is
worth keeping — the repository is disposable and expected to be deleted after the pass.

```bash
npm test    # node --test test/
```
